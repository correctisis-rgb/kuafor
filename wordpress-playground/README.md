# Hakan Kuaför WordPress Playground

- Customer registration and appointment area: https://playground.wordpress.net/?blueprint-url=https%3A%2F%2Fraw.githubusercontent.com%2Fcorrectisis-rgb%2Fkuafor%2Fmain%2Fwordpress-playground%2Fkuafor-randevu-blueprint.zip&login=no&url=%2F%23randevu
- WordPress admin dashboard demo: https://playground.wordpress.net/?blueprint-url=https%3A%2F%2Fraw.githubusercontent.com%2Fcorrectisis-rgb%2Fkuafor%2Fmain%2Fwordpress-playground%2Fkuafor-playground-blueprint.zip&login=yes&url=%2Fwp-admin%2F

The customer bundle does not log in as admin, so visitors can register or sign in before booking. The admin bundle opens the isolated Playground dashboard with its demo admin session.

Each visitor gets a separate database; accounts and appointments are not shared. The packages exclude local customer records, appointments, WordPress configuration, SMTP credentials, and account passwords.

Current demo business settings: Saç kesimi (500 ₺ / 30 min), Sakal tıraşı (300 ₺ / 30 min), Saç + sakal (800 ₺ / 60 min); opening 09:00–18:00, break 12:30–13:30, Sunday closed; barbers Hakan, Ahmet, Mehmet.

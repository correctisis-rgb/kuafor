# Hakan Kuaför WordPress Playground

Two public demo entry points are available. Each visitor receives an isolated WordPress Playground database; customer accounts and appointments are not shared.

- Customer registration and appointment area: https://playground.wordpress.net/?blueprint-url=https%3A%2F%2Fraw.githubusercontent.com%2Fcorrectisis-rgb%2Fkuafor%2Fmain%2Fwordpress-playground%2Fkuafor-randevu-blueprint.zip&login=no&url=%2F%23randevu
- WordPress admin dashboard demo: https://playground.wordpress.net/?blueprint-url=https%3A%2F%2Fraw.githubusercontent.com%2Fcorrectisis-rgb%2Fkuafor%2Fmain%2Fwordpress-playground%2Fkuafor-playground-blueprint.zip&login=yes&url=%2Fwp-admin%2F

The bundles include the theme, appointment plugin, and non-sensitive business configuration. They exclude the local database, customer records, appointments, WordPress configuration, SMTP credentials, and account passwords.

The previous Firebase/Expo application files have been removed from the current branch. They remain in Git history and can still be recovered from older commits.

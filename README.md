# Hakan Kuaför WordPress Playground

A browser-based demo of the Hakan Kuaför appointment system.

Open the demo: https://playground.wordpress.net/?blueprint-url=https%3A%2F%2Fraw.githubusercontent.com%2Fcorrectisis-rgb%2Fkuafor%2Fmain%2Fwordpress-playground%2Fkuafor-playground-blueprint.zip

This Playground is public as a demo. Each visitor gets an isolated WordPress copy with its own database. Customer accounts and appointments are not shared between visitors.

The package includes the theme, appointment plugin, and non-sensitive business configuration. It excludes local customer records, appointments, WordPress configuration, SMTP credentials, and account passwords. Do not upload real customer information to this public repository.

The previous Firebase/Expo application files have been removed from the current branch. They remain in Git history and can still be recovered from older commits.
